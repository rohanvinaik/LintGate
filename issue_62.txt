## Scope
Phase 4 gate-context and confidence improvements.

## Dependency placement
- Phase: **4**
- Depends on: #65 (branch-aware text quality)

## Goal
Make symbol coverage findings context-aware and confidence-calibrated so partial-run results are interpretable by humans and MCP agents.

## Implementation guidance
1. Extend symbol finding emission context in `lintgate/channels/test_channel.py`.
- Extend `_emit_symbol_findings(...)` inputs with:
  - `coverage_pct: float | None`
  - `targets_mode: str` (`impacted` | `fallback` | `full` | `unknown`)
- Add to each finding evidence:
  - `is_partial_run`
  - `coverage_ok`
  - `coverage_pct`
  - `targets_mode`

2. Confidence modulation.
- Full run: `confidence=1.0`
- Partial + coverage_ok: reduced confidence (e.g. `0.6`)
- Partial + coverage_not_ok: intermediate (e.g. `0.7`)

3. Surface downgrade rationale.
- When severity is downgraded due partial-run context, append explicit rationale in message suffix.

4. Thread target mode through call chain.
- Determine mode in `execute()` and pass through `_run_symbol_gate(...)` to `_emit_symbol_findings(...)`.

5. Add reconciliation metadata to channel metrics.
- In `_build_channel_result(...)`, add `symbol_gate_context` block with the same gate-context keys.

## Test guidance
Add/update tests for test channel integration:
- `test_partial_run_confidence_reduced`
- `test_full_run_confidence_1`
- `test_gate_context_in_evidence`
- `test_downgrade_reason_in_message`
- `test_reconciliation_metadata_in_channel_result`

## Acceptance criteria
- Symbol findings include gate context + calibrated confidence.
- Downgrades are explicit and auditable.
- Channel metrics include reconciliation context for downstream consumers.
