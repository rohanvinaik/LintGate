## Goal
Fix symbol-coverage remediation text for branch-only misses and remove blank/line-centric suggestions when line data is absent.

## Implementation guidance
1. Add helper in `lintgate/channels/test_channel.py`.
- Implement `_build_symbol_suggestions(sr)` to generate guidance by evidence shape:
  - line-only
  - branch-only
  - mixed
  - no evidence fallback
- Always append waiver guidance as secondary suggestion.

2. Update symbol finding text construction.
- In `_emit_symbol_findings`, replace inline suggestion generation with helper output.
- When `missing_lines` is empty but branches exist, avoid `"missing lines:"` phrasing.
- Prefer message indicating uncovered branch count.

3. Keep evidence-first behavior.
- Preserve existing evidence payload keys.
- Include branch examples in suggestion text for branch-only cases (best effort, capped).

## Test guidance
Add/update tests in tests for test channel/symbol gate integration:
- `test_suggestion_line_only`
- `test_suggestion_branch_only`
- `test_suggestion_mixed`
- `test_suggestion_no_evidence`
- `test_message_text_branch_only`

## Acceptance criteria
- No blank line-list suggestions for branch-only findings.
- Branch-only findings produce branch-focused actionable text.
- Existing line-only behavior remains intact.
